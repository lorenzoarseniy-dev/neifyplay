# NeiFyPlay

Готовый сайт мини-кинотеатра с сериалом «Бессмертный», видеоплеером и закрытой панелью администратора.

## Что умеет сайт

- Главная страница NeiFyPlay и карточка сериала «Бессмертный».
- Список серий и просмотр загруженных видео прямо на сайте.
- Предустановленная запись «Серия 1» — прикрепи к ней видео из панели администратора.
- Закрытый вход администратора без публичной регистрации.
- Загрузка новых серий, замена видео и удаление серий.
- Данные и видео сохраняются на серверном диске.

## Данные входа

- Логин: `NeiFy_Play`
- Пароль: `Claude`

Пароль `Claude` очень простой. До публикации сайта в интернете обязательно замени его на длинный уникальный пароль в файле `.env`. Не отправляй пароль другим людям и не публикуй `.env`.

## Запуск на компьютере

Нужен Node.js версии 20 или новее.

1. Распакуй архив и открой папку `NeiFyPlay`.
2. Скопируй `.env.example` в новый файл `.env`.
3. В `.env` замени `SESSION_SECRET` на случайную длинную строку. Для реального размещения также замени `ADMIN_PASSWORD`.
4. Открой терминал в папке проекта и выполни:

   ```bash
   npm install
   npm start
   ```

5. Открой в браузере `http://localhost:3000`.
6. Нажми «Войти» и используй заданные в `.env` логин и пароль.

## Как добавить серию

1. Войди как администратор.
2. Перейди в панель управления.
3. Чтобы загрузить видео для заранее созданной «Серии 1», выбери в списке «Загрузить / заменить видео: Серия 1».
4. Оставь название или измени его, добавь описание, выбери видео и нажми «Загрузить серию».
5. Чтобы добавить следующую серию, выбери «Добавить новую серию», укажи название и файл.

Лучше всего использовать MP4 (H.264/AAC) — этот формат поддерживается большинством браузеров. Максимальный размер одного файла — 1 ГБ.

## Публикация в интернете

Это полноценное серверное приложение Node.js, а не только макет страницы. Для публичного сайта нужен хостинг, который поддерживает Node.js, HTTPS и постоянное дисковое хранилище.

После загрузки проекта на хостинг:
- установи зависимости командой `npm install`;
- укажи переменные окружения `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `NODE_ENV=production`, `PORT`;
- включи HTTPS;
- при размещении за reverse proxy задай `TRUST_PROXY=1`;
- подключи постоянный диск и сохрани на нём папки `data/` и `uploads/`.

Важно: не используй временное файловое хранилище хостинга — после перезапуска оно может очищаться. Также не размещай сайт с паролем `Claude`: сначала измени его.

## Структура

- `server.js` — сервер, авторизация, база данных, загрузка и выдача видео.
- `public/` — сайт, стили и клиентский JavaScript.
- `data/` — SQLite-база и сессии.
- `uploads/` — загруженные видео.
- `.env.example` — пример конфигурации.
