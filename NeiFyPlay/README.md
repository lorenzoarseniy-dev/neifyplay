# NeiFyPlay

Готовый сайт мини-кинотеатра с сериалом «Бессмертный», видеоплеером и красивым современным дизайном.

## Что умеет сайт

- Главная страница NeiFyPlay.
- Карточка сериала «Бессмертный».
- Список серий.
- Просмотр видео прямо на сайте.
- Удобный видеоплеер.
- Поддержка мобильных устройств и компьютеров.
- Тёмный современный дизайн.
- Быстрая загрузка страниц.

## Просмотр сериала

На главной странице находится сериал «Бессмертный».

Посетитель может:
1. Открыть страницу сериала.
2. Выбрать нужную серию.
3. Смотреть видео прямо на сайте.

Предусмотрена предустановленная запись «Серия 1».

Видео размещаются на сервере и воспроизводятся через встроенный видеоплеер.

Сайт предназначен исключительно для просмотра сериалов.

## Запуск на компьютере

Нужен Node.js версии 20 или новее.

1. Распакуй архив и открой папку `NeiFyPlay`.
2. Открой терминал в папке проекта.
3. Выполни:

   `npm install`

4. Затем выполни:

   `npm start`

5. Открой в браузере `http://localhost:3000`.

## Публикация в интернете

Для публикации сайта нужен хостинг с поддержкой Node.js.

Необходимые условия:
- Node.js 20 или новее.
- HTTPS.
- Постоянное дисковое хранилище.
- Поддержка запуска серверного приложения.

Видео и данные сайта должны храниться на постоянном диске сервера.

## Структура проекта

- `server.js` — сервер сайта.
- `public/` — главная страница, стили и JavaScript.
- `data/` — данные сайта.
- `uploads/` — видеофайлы.
- `package.json` — настройки и зависимости проекта.
